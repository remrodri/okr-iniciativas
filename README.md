# OKR Iniciativas

Aplicación colaborativa para diseñar y priorizar iniciativas de OKR, desde la
definición de la situación actual y deseada hasta la priorización mediante ICE.

## Método de desarrollo

El proyecto utiliza el flujo SDD del ejemplo `hello-sdd`:

1. Constitución.
2. Spec en notación EARS.
3. Clarificación con revisión QA.
4. Plan técnico sin código.
5. Tareas pequeñas, ordenadas y verificables.
6. Implementación de una tarea por vez, con pruebas primero.
7. Validación final requisito por requisito.

La especificación inicial está en
[`specs/001-sesion-priorizacion-okr/spec.md`](specs/001-sesion-priorizacion-okr/spec.md).
